## Destination

双击就能用的 Windows 小工具：在一张或多张图片上按需设定节奏（跟 BGM 走 / 自设总长或单张秒数），粘贴一个视频地址（B 站 / 抖音 / YouTube / 快手等，或直接给本地音视频文件）自动取其整条音轨当 BGM，窗口里能预览，一键导出 1080p30 的 mp4（H.264 + AAC），并附一页用法说明。技术栈与交互都取“够用即止”，不引入需要额外安装的重型依赖。

## Decisions so far

- [02 选型：轻量预览编辑器 + 出片栈](issues/02-选型-轻量预览编辑器-出片栈.md)：PyQt6 单窗口 + QMediaPlayer 嵌窗播 540p 预览 + 一条 ffmpeg `filter_complex`（每图 `trim=end_frame` 锁帧）出 1080p30 H.264/AAC；备选 tkinter；MoviePy 慢 12–14×、纯图片 concat 会漂。
- [01 B 站音轨直取：无登录最高音质与边界](issues/01-b-站音轨直取-无登录最高音质与边界.md)：不需要 Cookie，`fnval=16&platform=pc` 取 dash.audio 并按 bandwidth 选最大；会员番剧 `is_preview=1` 只有试看 durl，短链失效是 200+`code:-404` 而非 3xx；附 `probe/bili_audio.py`。
- [03 编辑器窗口与时间线交互定稿](issues/03-编辑器窗口与时间线交互定稿.md)：单窗口（左列表 / 中预览 / 下色带 / 上工具条）；「跟 BGM」= 音乐时长 ÷ 张数均分，改一张其余按比例让位；逐张模式允许短于音乐（裁尾淡出）；点色带跳转、540p 预览片按需刷新。
- [05 画面、音频默认值与导出规则定稿](issues/05-画面-音频默认值与导出规则定稿.md)：模糊铺底不裁图、硬切、淡入 0.5s / 淡出 1.5s、1080p30 H.264 crf20 + AAC 192k、导出到图片同目录 `slideshow_YYYYMMDD_HHMM.mp4` 重名加序号。
- [04 按定稿实现工具并跑通一条真实出片](issues/04-按定稿实现工具并跑通一条真实出片.md)：`.scratch/pic2video/pic2video.py`（单文件窗口 + 命令行）+ `bili_audio.py` + `启动.bat` + `README.md`；真实 BV13qs46FE9C 取 661 s 音轨出 1080p30/19841 帧成品，裁尾、循环、30 图、窗口导出四条路径与 13 条时间线单测全过。
- [06 设置菜单：导出目录、输出规格、铺底与转场、跟随系统音频设备](issues/06-06-设置菜单-导出目录-输出规格-铺底与转场-跟随系统音频设备.md)：设置写 `settings.json`（记住上次）；导出目录＝设置默认值 + 每次保存框可改；30/60fps、画质三档、硬切/淡入淡出（比例与铺底的档位后来由 07 扩写）；预览音频不手选、跟随 Windows 默认设备（`audioOutputsChanged` 重指）；顺带修 60fps 帧数写死 30 的 bug。
- [07 画面比例档位与背景（颜色/图片/视频/模糊）可配](issues/07-画面比例档位与背景-颜色-图片-视频-模糊-可配.md)：比例扩到 16:9/9:16/1:1/4:5/4:3/21:9/3:4/2:3/自定义（选档位按短边 1080 自动填宽高，宽高也能手改，改了就跳「自定义」）；铺底变五种：原图铺底 / 纯色留白（自选颜色）/ 自定义背景图 / 自定义背景视频 / 裁切铺满，背景模糊独立成开关；老配置 blur→own、black→color 兼容。
- [08 多语言（5 种）与简洁/专业模式切换](issues/08-多语言-5-种-与简洁-专业模式切换.md)：新增 `i18n.py`（140 条词条 × 繁中/英/日/韩，中文原文当 key，缺词条回落中文，`system_locale()` 读 Windows 界面语言且可在设置里手动覆盖并记住），可见文案全走 `tr()` 而内部值（quality/ratio/fit）保持中文；工具栏右侧「简洁 / 专业」开关记住上次，简洁模式的设置窗只留 6 项必要设置（设置窗的收窄保持，工具条后来由 09 继续收窄）；换语言/换模式立即 retranslate 并按文案加宽窗口。
- [09 简洁模式再简化：只留加图片/导出与右键菜单](issues/09-简洁模式再简化-只留加图片-导出与右键菜单.md)：简洁模式工具条只剩「加图片 / 导出视频」+ B 站链接行，设置入口缩成右上角「⋯」；上移/下移/删除/改秒数改走列表右键菜单（两个模式都有，编辑能力仍一致）；没有「刷新预览」按钮 → `_mark_stale()` 挂 900 ms 防抖自动重渲预览。
- [默认简洁模式 + 深浅主题 + 主色对撞色 + 色环取色](issues/10-默认简洁模式-深浅主题-主色对撞色-色环取色.md)：首次打开进简洁模式；新增 theme.py（跟随系统/浅色/深色三档 + 只挑一个主色，按色环 180° 自动出对撞色，readable_accent 保证按钮文字对比度），设置里改用色环取色；QSS 的下拉/微调箭头改为按配色现画的 PNG（Windows 画不出 border 三角）。
- [多平台 BGM：抖音/YouTube 等链接与本地文件（yt-dlp 按需装删）](issues/11-多平台-bgm-抖音-youtube-等链接与本地文件-yt-dlp-按需装删.md)：新增 audio_source.py 分 local/bili/web 三种来源——B 站仍走 bili_audio，抖音/YouTube/快手/小红书/微博走 yt-dlp（设置里一键装/删到 tools/，约 21 MB），本地音视频拖进窗口直接当 BGM；命令行 --audio 也收平台链接。
- [12 v1.0.1 发版：把颜色范围修复带进 exe 并撤下 v1.0.0 下载包](issues/12-v1.0.1-发版-颜色范围修复带进-exe-并撤下-v1.0.0-下载包.md)：build.bat 重打包，跑 exe 验到 ffprobe 报 `tv / bt709`（单测 216 条全过）；发 v1.0.1 并标 Latest，zip 48,134,812 B、线上 digest 与本地 sha256 一致，顶层 `Pic2Video\` 解压即用；v1.0.0 的 asset 撤下、正文标「已被 v1.0.1 取代」，标签留作历史。
