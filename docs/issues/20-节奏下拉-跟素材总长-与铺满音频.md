## Question

用户 m05292 第 7、8 条：把「跟 BGM」改成下拉，可选跟背景音乐 / 跟素材总长（确认含义＝片头片尾 + 视频元素的总长，图片按此均分、不含音频块）等档位；另外同时选中一个图片/视频与一个音频时，右键菜单给「图片/视频铺满音频」——图片就把时长改成音频时长，视频比音频短就循环、比音频长就从结尾裁短。

## Answer

**节奏下拉**：「跟 BGM」那个单选换成 `QComboBox cmb_rhythm`，两项＝跟背景音乐（bgm）/ 跟素材总长（material），旁边「自设总长」「逐张秒数」两个单选不变；`Project.mode` 加 `material`，`MODE_LABELS` 同步，设置里的「默认节奏」也跟着多一档。

「跟素材总长」的算法按用户当场选的那种：**每张图 = 素材总长 ÷ 图片数**，素材总长 = 片头 + 片尾的总长（不含音频块）。没有片头片尾时这个数算出来是 0，此时不动图片（沿用各自秒数），不会把片子压没。实现是 `Project.material_len()` + `Project.apply_material()`，`normalize()` / `frame_counts()` 都会先按当前模式铺一遍，所以预览、出片、状态栏一致。

**铺满音频**：同时选中一个画面元素和一条音频时，画面右键菜单多一项「画面铺满这条音频」（`Window.on_fill_audio`）。图片走 `Project.set_duration`（跟 BGM/自设总长模式下其余图片按比例让位，最小 0.2 秒），片头/片尾走新增的 `Project.set_video_len`：`Clip.dur` 与源片长解耦，比音频短的在 render 里给该输入加 `-stream_loop -1` 循环补满，比音频长的由既有的 `trim=end_frame` 截短。改时长记一步历史（「铺满音频」）。

验证：`PIC2VIDEO_SHOT_RHYTHM` 打印下拉两项并把模式切到 material（2 图、无片头片尾 → 时长不变，符合预期）；`PIC2VIDEO_SHOT_FILL` 打开画面右键菜单确认出现「画面铺满这条音频」，触发后 6.0 秒音频把首图拉到 5.8 秒、另一张让到下限 0.2 秒，历史多一步「铺满音频」。真出片验证 1 秒视频要求放 3 秒 → 成片 4.0 秒（循环补齐）。单测新增第 35 组 15 条，全套 329 条全过。
