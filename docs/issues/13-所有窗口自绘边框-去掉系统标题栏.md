# 13 所有窗口自绘边框：去掉系统标题栏

Type: wayfinder:task
Status: resolved
Parent: 00
Blocked by: —

## Question

用户觉得 Windows 默认标题栏丑、跟软件配色不统一，要求把主窗口和软件里所有窗口都换成自己画的边框。

## Answer

- 主窗口 `Window` 与所有弹窗都走 `FramelessWindowHint` + 自绘 `TitleBar`（图标 + 标题 + 最小化/最大化/关闭），窗口一圈细边用 QSS `QMainWindow#frame, QDialog#frame` 画，颜色跟主题/主色走。
- 拖动、双击最大化、八方向拉伸都靠 `nativeEvent` 里的 `WM_NCHITTEST` 命中测试（`hit_test()`，边缘 6 px，坐标按 `devicePixelRatioF` 折算物理像素）。
- **坑**：PyQt6 里子类化 `nativeEvent` 后调用 `super().nativeEvent()` 会直接段错误（`0xC000041D`，无 traceback）；改成未处理时 `return False, 0`。
- 原来的 `QMessageBox` / `QProgressDialog` / `QInputDialog` 全部换成自绘的 `MsgBox` / `ProgressDialog` / `NumberDialog`；文件选择换成内嵌 `QFileDialog`（`DontUseNativeDialog`）外面套自绘边框的 `FileDialog`，前进/后退/上一级三个箭头用 `QPainter` 按 `QPalette.WindowText` 重画。
- 样式与调色板改贴到 `QApplication` 全局（原来只贴窗口，parent 为空的对话框拿不到样式）；`app.setStyle("Fusion")` 统一画法。
- Qt 自带控件（文件框的表头、按钮）通过 `QTranslator` 加载 `qtbase_<lang>` 译文，跟界面语言一致。
- 验证：`WM_NCHITTEST` 探针九个位置全部返回正确命中码（10/11/12/15/13/17/2/1/1）；深浅两套主题的主窗口、设置、色环、消息框、数字框、文件框截图确认；两次窗口冒烟都正常出片（1920x1080 / 30fps / 6.000 s）；单测 226 条全过（新增第 29 组 10 条防回归）。
- 取舍：自绘文件框没有系统的「快速访问 / 最近位置」侧栏，路径可以手输 —— 已在 README 已知限制里写明。
