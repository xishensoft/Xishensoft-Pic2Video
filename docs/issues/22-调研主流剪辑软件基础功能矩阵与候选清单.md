## Answer

清单写在 [docs/research/剪辑软件基础功能清单.md](../research/剪辑软件基础功能清单.md)（259 行，八个方向各一张表 + 外部资源格式生态 + 推荐三批 + 两大风险；ffmpeg 事实以本机 9.1 构建与官方 filter 文档为准，竞品以各家官方手册为准，拿不到官方页的标「未验证」）。

**最重要的结论是架构分水岭**，比功能清单本身更值钱：

| 层级 | 能力 | 拓扑 | 判断 |
| --- | --- | --- | --- |
| L0 元数据/单段滤镜 | 工程文件、入出点、分割、字幕烧录、转场预设、导出预设、eq/LUT、音量包络、波形旁路 | 不变（仍是段链 + concat/xfade） | 1.x 全做，成本在前端与数据模型 |
| L1 单层叠加 | 单层画中画、一个叠加轨 | **变**（基底 + overlay pass） | 1.x 可做一层，是通往合成器的最小台阶 |
| L2 任意多轨/嵌套 | 多视频轨、自由层、嵌套序列 | **大改**（Timeline/Track/Clip + 合成器 + 混音器） | 2.0 再说，1.x 只留数据结构余地 |

关键判断：**入出点不改拓扑**（`Clip` 加 `src_in/src_out`、`frame_counts()` 按 `(out-in)*fps`、每段 `trim` 改起点即可）；**真正改拓扑的是叠加层**；**任意多轨是 2.0 的 pivot，不要靠「先加一条轨」偷偷开始**。

**工作量判定**：字幕 中（libass 字幕模型）／转场 小（xfade 已有骨架）／调色 中（LUT 校验与色彩范围）／画中画 大（overlay 拓扑与图层模型）／音频 中（波形与包络）／时间线 中（入出点与分割；任意多轨另计大）／导出 小（尺寸预设已有，补封面）／工程 小（序列化与自动保存）。

**实测（本机 ffmpeg 9.1，纯滤镜，10 s/30 fps）**：3 层 overlay 0.63 s、10 条 drawtext 0.22 s、lut3d 1.07 s、libass 字幕 1.93 s（最重的常规项）、内置 xfade 0.25–0.34 s 而 custom expr 是它的 4.5 倍、showwaves 0.53 s。结论：**滤镜不是瓶颈，瓶颈是「改一个参数就重建整条 graph 并重渲整段样片」**；只有 libass 与 custom xfade 会明显拖慢 540p 预览。

**推荐三批**：① 工程文件 + 自动保存 + 最近项目、入出点/分割/拖拽裁剪、SRT/ASS 字幕导入与烧录、8–12 个 xfade 转场、平台导出预设 + 封面；② 单层画中画、eq + .cube LUT + 强度、波形/音量包络/每段增益、外部资源包（字体/LUT/转场预设 + zip）；③ 不碰：任意多轨与嵌套、AI 字幕、关键帧曲线、模板商店/云、原生插件 ABI。只做一件就做工程文件；只做两件再加「入出点 + 分割」。

**外部资源边界的硬事实**（23 号票的输入）：`xfade` 只吃内置名或 `expr`，**不接受任何外部文件**，所以「转场包」只能做成「命名预设 + 参数 + 可选 custom expr」，不能承诺剪映同款；Kdenlive 的 `.pgm` 灰度遮罩是 MLT 的能力不是 ffmpeg 的。字体可以真导入（ttf/otf/ttc，应用私有目录 + 显式 `fontfile` 或 `fontsdir`；TTC 只取 face 0，要粗体得单独带文件；**drawtext 没有 CJK 逐字形回退**——本机用 arial 渲中文得到豆腐块，实测必须给含中文的字体文件）。滤镜包应定义成「LUT + 参数预设」而不是「任意 filter 字符串」。zip 安装只收 `manifest.json` + sha256 + 白名单 `kind`（transition/font/lut/preset），安装到临时目录校验后原子改名，拒绝绝对路径/`..`/符号链接/可执行文件，限制体积与条目数防 zip bomb。

**两大风险**：① 架构半途——把单层叠加做成隐形多轨合成器，破坏现有的帧数守恒、预览与撤销；控制线是「一条基底链 + 最多一层 overlay，关掉叠加层必须退回纯 concat」。② 外部资源承诺过度；控制线是转场只承诺预设包、字体只收可再分发授权、zip 只收带 manifest 的白名单类型。

**顺手发现的结构债**：`Project.to_state()` 现在只服务撤销（数组元组、无版本号），工程文件、字幕、转场、叠加层、LUT 参数都需要落盘位置，不先升级成带 `version` 的 dict 就会每个功能自带一套临时序列化。
