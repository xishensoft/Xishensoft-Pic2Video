# 17 快捷键可在设置里自定义，默认对齐剪辑软件惯例

Type: wayfinder:task
Status: resolved
Parent: 00
Blocked by: 16

## Question

用户 m05292 第 2 条：设置里加「快捷键」页，各个命令都能改键；默认值按一般剪辑软件的对应快捷键来（撤销 Ctrl+Z、重做 Ctrl+Shift+Z、保存 Ctrl+S、打开 Ctrl+O、删除 Delete、播放/暂停 Space、导出 Ctrl+E 等）。

## Answer

设置里多了第 7 页「快捷键」，七个动作各一个 `QKeySequenceEdit`（点一下再按键就改，只收单段序列）：加图片 / 导出视频 / 撤回 / 还原 / 播放暂停 / 删除素材 / 刷新预览。设置存进 `settings.json` 的 `shortcuts` 字段，接受后立刻 `_bind_shortcuts()` 重建全部 `QShortcut`（旧的先 disable + deleteLater，不会重复响应）。

默认值按剪辑软件惯例：导入 **Ctrl+I**、导出 **Ctrl+M**（Pr 的 Export Media）、撤回 **Ctrl+Z**、还原 **Ctrl+Shift+Z**、播放暂停 **Space**、删除 **Delete**、刷新预览 **F5**。原来「Ctrl+O 加图 / Ctrl+S 导出」的临时键被替换（之所以选 Ctrl+I / Ctrl+M，就是用户要求的「跟剪辑软件一致」）。

细节：
- 同一个键被两个动作占用时，点「好」会被拦下来并提示「「A」和「B」都设成了 X，改一个再来」，对话框不关。
- 清空某个键 → 保存时回落到该动作的默认键，不会变成“无快捷键”。
- 设置页有「恢复默认」一键还原。
- `_sanitize` 会丢掉不认识的键名、空值和非字符串，缺的补默认；写坏成字符串也不会崩。
- 在简洁模式下这一页不出现（`pro=True`），快捷键照旧生效。

验证（本机实跑）：
- 单测第 33 组 10 条：默认值、坏值回落、自定义能存住、坏结构不炸、七个动作都有名字、旧绑定会被清掉、按设置绑定、设置里有这一页、重复键被拦、能恢复默认 —— 全绿。
