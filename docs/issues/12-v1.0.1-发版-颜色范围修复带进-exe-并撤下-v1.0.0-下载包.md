## Answer

已完成。

**打包**：`cmd /c "build.bat < nul"`（bat 末尾有 `pause`，测试时把 stdin 接到 nul 让它自己走完），PyInstaller onedir 构建成功，`dist\Pic2Video\Pic2Video.exe` + `_internal`。

**验收（跑的是 exe，不是源码）**：`PIC2VIDEO_SHOT` + `PIC2VIDEO_EXPORT_PATH` 冒烟，EXIT=0，出 1920x1080 30fps 180 帧 6.000 s 的 mp4；ffprobe 读回 `color_range=tv color_space=bt709 color_transfer=bt709 color_primaries=bt709`，AAC 48 kHz 立体声。单测 216 条 ALL PASS。

**发布**：`Pic2Video-v1.0.1-win64.zip`（48,134,812 B，sha256 `6e567be32580e196dddd918d7bd9f016c4534be864760f163453688b1e3b454d`，与线上 asset digest 一致），zip 内顶层是 `Pic2Video\`，解压即用。

- v1.0.1 建成、标 Latest：https://github.com/xishensoft/Xishensoft-Pic2Video/releases/tag/v1.0.1
- v1.0.0 的 zip asset 已删除，正文顶部加了「已被 v1.0.1 取代」的说明并改掉下载那句，标签保留作历史。

**顺手**：README 发灰那条改成指向 v1.0.1（提交 a0298ac）。

**线上包回下载复验（m04182 追加）**：`gh release download v1.0.1` 重下 48,134,812 B / 33 s，sha256 与本地 zip 一致；解压到 `%TEMP%` 后顶层是 `Pic2Video\`，`Pic2Video\Pic2Video.exe` 与本地 `dist` 那份 sha256 完全相同（`d0466ce1…93ec090`）；跑该 exe 冒烟 EXIT=0，出 1920x1080 / 30 fps / 180 帧 / 6.000 s，ffprobe 报 `color_range=tv color_space=bt709 color_transfer=bt709 color_primaries=bt709`，AAC 48 kHz。即线上包端到端可用，不是只有摘要对得上。
