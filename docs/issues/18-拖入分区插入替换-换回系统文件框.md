# 18 拖入图片的左右三分区插入/替换 + 换回系统文件框

Type: wayfinder:task
Status: resolved
Parent: 00
Blocked by: 16

## Question

用户 m05292 第 4、5 条：从外部拖图片进时间线时，鼠标落在某元素中间三分之一＝替换这张，左三分之一＝在该元素左边插入，右三分之一＝右边插入。另外把自绘文件选择框换回系统原生对话框（自绘的侧栏/位置太少）。

## Answer

两件都落地了。

**拖入三分区**：`ImageList` 自己接外部拖入，`_hit(pos)` 用 `(x - rect.left) / rect.width()` 判段：< 1/3 插到这个元素左边、> 2/3 插到右边、中间三分之一＝替换它；空白处拖入＝加到末尾（片尾之前）。落点有提示：替换画半透明高亮框，插入画 3px 竖线，颜色取主题 Highlight。`dropEvent` 发 `drop_files(paths, row, zone)`，`Window.on_drop_into_list` 负责展开文件夹、按 QImageReader 过滤坏图、调 `Project.insert_images` / `Project.replace_image` 并记一步历史（「加图片」/「替换素材」）。替换只换图片，越界或落到片头/片尾上会退回成插入；替换多张时第一张替换、其余插在后面。

**换回系统文件框**：`FileDialog` 从「自绘壳 + QFileDialog(DontUseNativeDialog)」改成薄包装，三个 classmethod 直接调 `QFileDialog.getOpenFileNames / getSaveFileName / getExistingDirectory`，调用点签名不变。代价是边框不跟主题统一，换来快速访问、最近位置、网盘挂载都在（README 已知限制已写）。

验证：冒烟钩子 `PIC2VIDEO_SHOT_DROP` 依次发 before@1 / replace@0 / after@0，顺序变成 `land, main-window-dark, port, sq` 再换成 main-window-dark；截图确认替换高亮框与左侧竖线都在。单测新增第 34 组 15 条（插中间、越界插末尾、负下标、替换不改时长、替换保留淡入淡出、片尾不被替换、三段判定、扩展名过滤、文件框三件套、保存框补后缀等），全套 329 条全过。
