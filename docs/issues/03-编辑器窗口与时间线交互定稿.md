交互定稿（单窗口 PyQt6，左边列表、中间预览、底下色带、顶部工具条）。

**布局**
- 顶部：加图按钮；排序按钮（上移/下移/删除，拖拽之外的兜底）；三个单选 `跟 BGM / 自设总长 / 逐张秒数`（默认跟 BGM）；BGM 链接输入框；导出按钮。
- 左侧：图片列表（缩略图 + 每张秒数），支持把文件拖进窗口、列表内拖拽排序、双击秒数直接改。
- 中间：QMediaPlayer 播 540p 预览片，循环；参数一改，按钮变「刷新预览」。
- 底部：按比例分块的色带时间线；点块 → 预览跳到该图起点；拖块边缘 → 改这张的时长。

**时长语义（用户确认）**
- **跟 BGM**：每张 = BGM 时长 ÷ 张数，均分得到初值；手改某一张，其余几张**按原比例自动重分配**，总长恒等于 BGM。图片不循环，永远刚好铺满音乐。
- **自设总长**：总和 = 设定值，同样均分起步、改一张其余按比例让位。
- **逐张秒数**：各自独立，总长 = 求和。比音乐短 → 音乐裁尾并淡出；比音乐长 → 音乐循环补足、结尾淡出。

**BGM**：链接粘进输入框即自动解析，显示进度与「时长 3:42」；失败显示具体原因 + 重试按钮。

**预览**：540p 预览片生成后嵌窗循环播放；点色带块跳转到该图起点继续播；改图/改时长/换音乐后标记「预览已过期」，不自动重渲染。

关键一句：**「跟 BGM」是均分，不是循环铺图**——这是用户明确纠正过的语义。
