验证（2026-11-22 本机实测）：

1. 真实 B 站链接 `BV13qs46FE9C`（11:01 短片）：无 Cookie 取到 661.37 s 音轨，跟 BGM 模式 3 张图分得 220.46/220.46/220.46 s，产出 19841 帧 / 661.367 s / 1920x1080 / 30fps / AAC 48k 立体声，17.4 MB，用时 117 s。
2. 裁尾路径：同一音轨 + `--total 4` → 12.000 s / 360 帧，音频 `atrim` 到 12.000 s。
3. 循环路径：7 s 本地音轨 + `--total 5`（15 s 片）→ 音频 loop 到 14.957 s，音画同长。
4. 30 张图（命令行超长，自动走 `-/filter_complex` 文件路径）→ 7.000 s / 210 帧。
5. 窗口：真实窗口截图确认布局（左列表 / 中预览 / 下色带 / 上工具条），屏录确认 540p 预览片确实在窗口里播放；在窗口里点「导出视频」产出 `slideshow_20261122_2233.mp4`（1920x1080 / 210 帧 / 7.000 s / AAC 48k 立体声，192904 B）。
6. 单测 13 条全过：跟 BGM 均分、改一张总长守恒、0.2 s 下限夹取、自设总长、逐张秒数、增删图守恒、随机 200 组帧数对齐 `round(total*30)`、排序。

实现要点（与 02/03/05 定稿一致）：每图 `-loop 1 -framerate 30` + `trim=end_frame` 锁帧，背景 `scale increase + crop + gblur sigma=40 + brightness -0.08`、前景 `scale decrease` 居中 overlay，`concat` 后与音频一起出 1080p30 crf20 / AAC 192k / faststart；音频不足时 `-stream_loop -1` 补足，超出时 `atrim` 裁尾，两端淡入 0.5 s / 淡出 1.5 s；命令过长自动改走 `-/filter_complex` 临时文件（UTF-8 无 BOM）。

失败路径已落实：图片读不了在加图时提示并跳过；ffmpeg 非零时窗口弹最后 8 行 stderr；B 站错误沿用 01 的中文映射（试看/地区/版权/风控等）。「记住上次设置」按“够用即止”不做。
