# 09: 简洁模式再简化：只留加图片/导出与右键菜单

Type: task

Status: resolved
## Question

票 08 落地后用户（m01105）继续要求：「简洁模式还能不能再简化，比如只留加图片、B 站链接、导出三个按钮」。
提问三题后拍板（m01107）：

1. 工具条只留「加图片 + B 站链接框 + 导出视频」（上移/下移/删除、设置、时长三选一、总长输入全藏）。
2. 藏掉「设置」后，窗口右上角放一个「⋯」小按钮进设置。
3. 藏掉上移/下移/删除后，列表加**右键菜单**（上移 / 下移 / 删除 / 改这张秒数）。

## 决议

- `Window._apply_ui_mode()`：简洁模式隐藏 上移 / 下移 / 删除 / 设置 / 时长三选一 / 总长输入 / 刷新预览，
  露出右上角「⋯」（`btn_more`，`fixedWidth 34`，tooltip「设置」）；专业模式反过来。
- 简洁模式没有「刷新预览」按钮 → `_mark_stale()` 里挂一个 900 ms 的 `auto_timer` 自动重渲预览
  （加图 / 换音乐 / 改设置后自己跟上；切回专业模式就停表）。
- 列表右键菜单 `on_list_menu()`：上移 / 下移 / 删除 / 改这张的秒数；没选中任何一项时四项置灰。
  两个模式都有，所以「编辑能力一样」这句仍然成立。
- 简洁模式的时长模式沿用 `settings["mode"]`（这项在专业模式里改），不额外加开关。

## Answer

简洁模式缩到两个按钮 + ⋯ 进设置 + 右键菜单 + 自动预览，已实跑验证。
