# 01: B 站音轨直取：无登录最高音质与边界

Type: research

Status: resolved
## Question

给定一个 B 站视频地址（BV/av/完整 URL/b23 短链/带分P参数），在没有登录 Cookie 的条件下，稳定拿到整条音轨的最佳做法是什么？

要回答：
(a) 首选接口与参数：wbi/view、wbi/playurl 的 fnval 选择；dash audio 30280 是否需要登录；durl 回退到什么音质；
(b) b23 短链与分P的解析；
(c) 付费/充电专属/试看/直播/番剧 的失败表现，以及给用户的可读报错；
(d) 音质上限；若确实需要 Cookie，最简的获取与使用方式（不要求用户装扩展）；
(e) 一段可直接放进工具的函数级配方（Python，仅标准库 + 现有 ffmpeg）。

产出：优先实际跑通仓内已知 BV（`.scratch/fm1145-video-pipeline/xd/audio/` 里那几个，或任意公开 BV），记录实测结果；笔记写 `.scratch/pic2video/notes/bilibili-audio.md`。

调研完成，笔记：`.scratch/pic2video/notes/bilibili-audio.md`（531 行，含实测表、错误码映射、可直接用的 `probe/bili_audio.py`）。

**结论：整条链路不需要 Cookie**，UA + Referer 足够。
- 取 cid：`x/web-interface/wbi/view`（bvid/aid 都行，一次拿到 bvid + cid）；`nav` 返回 -101 但 `wbi_img` 照常给，WBI 签名可用（不签名当前也能过，但建议签）。
- 取音轨：`fnval=16&platform=pc` 拿 dash.audio，**按 bandwidth 取最大**（30280/30232/30216 只是槽位 id，不是码率；同名 bandwidth 的两条是同一文件别名）。实测 87–323 kbps、AAC 48 kHz 立体声，时长与视频一致。
- 没 dash 时退回 `fnval=1` 的 durl：那是**整段 mp4**（55–130 MB），要下完再抽音轨，音质≈30280。`platform=html5` 只给 mp4。
- 无登录拿到 30250（杜比）/30251（Hi-Res）是不可能的，本项目也不需要（最终要转 16k 单声道）。

**必须防的坑**
- 短链 b23.tv：有效短码是 302 + Location；失效短码是 **200 + JSON code -404**，只看状态码会把失败当成功。
- 会员/付费番剧：code 0、`is_preview=1`、没有 dash，退回的 durl 只是试看（实测 60/180/360/600 s），不判断就会把试看当正片。
- 错误码映射：-404 不存在/不可见、62002 稿件不可见、-688 地区限制、-689 版权限制、-352 风控、87007 充电专属、87008 付费视频；直播 durl.length=0，不支持。
- url 有效期约 120 分钟，过期重调 playurl。

**交付**：`probe/bili_audio.py` 仅标准库 + ffmpeg，输入任意 B 站地址输出 m4a/wav，已跑 11 个用例。
