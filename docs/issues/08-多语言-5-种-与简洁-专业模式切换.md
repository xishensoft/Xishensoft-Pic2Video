# 08: 多语言（5 种）与简洁/专业模式切换

Type: task

Status: resolved
## Question

用户 m00848：「帮我做多语言功能，还有简洁模式与专业模式切换的功能，具体你问我」。
提问后拍板（m00855 / m00857）：

- 语言：简体中文 + English + 繁體中文 + 日本語 + 한국어 五种全要。
- 语言怎么决定：跟随 Windows 系统语言，设置里还能手动覆盖，并记住手动选择。
- 简洁模式保留：加图片/上移/下移/删除 + 时长三选一、B 站链接框、预览画面、时间线色带（日常全套编辑能力）。
- 模式入口：工具栏右侧一个「简洁 / 专业」开关，记住上次选择。
- 简洁模式的设置窗：「留一个没有一些比较专业麻烦的选项，流下必要选项的设置」。

## 决议

- 新增 `i18n.py`：以**中文原文当 key** 的五语言词条表（zh-CN 直接用原文，其它四种各一张表，缺词条回落中文），
  `tr(text, **kw)` 支持 `{name}` 占位；`system_locale()` 走 `GetUserDefaultUILanguage`，
  `locale_from_langid()` 把 0x0804/0x1004 → 简体、0x0404/0x0C04/0x1404 → 繁體、0x0411 → 日、0x0412 → 韩、其它 → 英。
- 只翻**看得见的文案**：`quality`（"标准"）、`ratio`（"自定义"）、`fit` 这些内部值保持中文，
  老 `settings.json` 和命令行参数不受影响；界面里用 `currentData()` 取内部值、`currentText()` 只用来显示。
- `Settings` 新增 `lang`（auto 或五选一）与 `ui`（simple/pro），都在 `_sanitize()` 里兜底。
- 双模式：工具栏最右一个按钮显示当前模式（简洁模式 / 专业模式），点一下切换并立即写 `settings.json`。
  简洁模式只藏设置窗里的专业项（分辨率手填、帧率、留白颜色、背景文件、背景模糊、默认节奏、
  逐张秒数、音乐淡入淡出、转场、预览音频输出），编辑能力一项不少。
- 换语言立即生效：`Window.retranslate()` 重设全部文案 + 重建列表/状态栏，并按新文案把窗口拉宽，
  避免英文/日文把按钮文字挤掉；设置窗下次打开即用新语言。
- B 站错误提示按错误码查译文（`bili_message()`），拿不到码就回落 `user_message`。

## 实现

- 新增 `i18n.py`：140 条词条 × 4 种译文（繁體中文 / English / 日本語 / 한국어），简体直接用中文原文当 key；
  `tr()` 支持 `{name}` 占位、缺词条回落中文；`system_locale()` / `locale_from_langid()` 读 Windows 界面语言；
  `bili_message(err)` 按 B 站错误码查译文（19 个码）。
- `pic2video.py`：所有可见文案走 `tr()`（工具栏、设置窗、状态栏、对话框、时间线空态、列表项、命令行 help 与输出、RenderError）；
  `Settings` 加 `lang`（auto + 五选一）与 `ui`（simple/pro），都有兜底；
  下拉框改成「显示译文、`currentData()` 存内部值」，`quality`/`ratio` 等内部值仍是中文，老 settings.json 与命令行参数不变。
- 工具栏最右加「简洁模式 / 专业模式」按钮：显示当前模式，点一下切换并立即写 settings.json 记住。
  简洁模式下设置窗只留界面语言 / 默认导出目录 / 画面比例 / 成片尺寸 / 画质 / 画面铺底，
  其余专业项（分辨率手填、帧率、留白颜色、背景文件、背景模糊、默认节奏、逐张秒数、音乐淡入淡出、转场、预览音频输出）隐藏。
- `Window.retranslate()`：换语言或换模式后重设全部文案并重建列表/状态栏，不重开窗口；
  并按新文案的 sizeHint 给按钮/标签设最小宽度、必要时把窗口拉宽（否则英文/日文会把按钮文字挤掉）。
- README 补「语言与简洁/专业模式」一节、设置表加「界面语言」行、限制里说明只翻界面文案。
