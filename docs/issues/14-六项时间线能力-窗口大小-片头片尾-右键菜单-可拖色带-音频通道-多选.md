# 14 六项时间线/编辑能力：窗口大小、片头片尾、元素右键菜单、可拖色带、音频通道、Shift 多选

Type: wayfinder:task
Status: resolved
Parent: 00
Blocked by: —

## Question

用户逐条提了六件事：设置里要能选启动窗口大小（最大化或固定尺寸）；要能配默认片头/片尾视频，加第一张图时自动拼在最前/最后、后加的图插在两者之间；时间线色块右键要能开该元素的菜单（先做淡入淡出开关）；点色带只会跳回开头，希望色带自己也能拖；要加音频元素通道，滚轮能改音量、右键菜单也能改；按住 Shift 多选元素后，菜单里统一改设置要一次生效。

## Answer

- **启动窗口**：设置 → 导出组加「启动时窗口」（记住上次 / 启动时最大化 / 固定大小），固定大小可填宽高，非该档时置灰。Qt 的 `isMaximized()` 对无边框窗口不可靠（实测 `showMaximized()` 只改了几何、状态标志仍是 False，最大化按钮会点不动），改成自己记 `_maxed` + `maximize_to_screen()` / `restore_down()` / `toggle_maximum()`，手动拉伸时自动退出最大化；探针实测 max 1536x864 → 还原 1300x760、fixed 1200x700、remember 1300x760。
- **片头片尾**：`Clip.kind` 增加 `intro` / `outro`（`Project.clips` 里与图片同轨），设置里两个路径；`add_images()` 在空项目时补片头片尾、之后的图插在片尾前；图片段的时长分配用 `fixed_span()` 扣掉固定段，改图片不影响片头片尾时长，片头片尾也能单独删。
- **BGM 只在图片段播**：按用户确认的口径，跟 BGM 时总长 = 音乐长度 + 片头 + 片尾；音频链按时间线分段——图片段 `atrim`、片头片尾段铺 `anullsrc` 静音再 `concat`，实测片头段 −91 dB、图片段 −24 dB。
- **元素右键菜单**：`Timeline` 新增 `menu = pyqtSignal(str, int, object)`，菜单构建抽成 `timeline_menu(kind, index)`（可被探针直接调用截图）。画面元素给「淡入淡出」（可勾选）、选中 ≥2 个时多一项「交叉淡化（与相邻元素）」、单个图片给「这张显示多久…」；音频元素给「音量 N%」（只读）、设置音量…、音量预设 25–200%、添加音频文件…、删除这条音频。
- **色带可拖**：左键拖空白＝拖播放头（`seeked`）；按住色块左右拖＝换位置（`moved` / `audioMoved`），右边界 5 px 内拖＝改时长。
- **音频通道**：时间线分上下两轨，音频每条一块，显示名字与音量；滚轮在音频块上每格 ±5%；`AudioClip` 支持多条叠加（各自起始时间、音量），渲染走 `adelay` + `amix=inputs=N:normalize=0`。
- **Shift 多选**：Shift / Ctrl 点选多个元素，菜单里的淡入淡出、交叉淡化、音量设置都在选中的整组上生效（音量夹在 0–200%）。
- **交叉淡化**：总长守恒——每条边界重叠 `round(xfade_sec*fps/2)` 帧、两侧各补一半，渲染用逐对 `xfade=transition=fade`；实测 3×2 s 交叉淡化仍是 180 帧 / 6.000 s。
- 修掉的实现 bug：`_xfade_plan(None)` 崩溃、`Project.audio_dur` setter 在没有 BGM 时静默失效、音频分段把标签当过滤串（`No such filter: ''`）、额外音频把整条链塞进 amix（`Invalid argument`）。
- 验证：单测 **269 条全过**（新增第 30 组，含真视频片头片尾、BGM 分段静音、第二条音频混入、交叉淡化帧数守恒、窗口模式探针）；GUI 冒烟出片 9.000 s（片头 1 + 音乐 6 + 片尾 2），时间线双轨与右键菜单截图确认。
