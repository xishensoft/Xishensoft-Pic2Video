## Question

用户 m05292 第 1、3 条：加撤回/还原；左上角素材区改成类似 PS 的分页，一页是素材顺序，另一页是历史操作记录，可在那儿撤回/还原。追问确认范围「全部都要，一个不落」——素材增删换位、时长/音量/淡入淡出/交叉淡化、音频轨、以及设置里的参数都要能一步步退回。

## Answer

做了「整份快照」式撤销栈：每步把 `Project.to_state()`（clips / audios / mode / music_start / music_len / total_setting）连同 `settings.data`（去掉窗口几何和上次导出目录）存一份，撤回/还原就是把快照装回去再整体刷新。素材和音频都是小对象，整份存最省事也最不容易漏，正好对上「一个不落」的要求。

- 栈上限 `_HISTORY_MAX = 120`；同类操作 1.2 秒内合并成一步（拖时间线边界会连发几十次，不合并就废了）；已经退回中间某步后再操作会截断重做分支。
- 记历史的动作共 17 处：加图片、删除素材、调整顺序（列表拖动/上下移/时间线拖块）、改时长（双击/时间线拖边界）、改节奏、加/删/移音频、改音量、淡入淡出/交叉淡化、改设置、换背景音乐。
- 界面：左侧改成 `QTabWidget`，「素材」是原来的列表，「历史」是 PS 那样的步骤列表（点任意一行跳回那一步）+ 撤回/还原按钮；工具条在专业模式下多了「撤回 / 还原」两个按钮，简洁模式仍只有快捷键。
- 快捷键：Ctrl+Z 撤回；Ctrl+Shift+Z 与 Ctrl+Y 还原（票 17 会把它们做成可改的）。
- 撤回设置项时会连带恢复界面语言 / 主题 / 配色并重贴样式，不是只改数值不生效。

验证（本机实跑）：
- 单测 `tests/test_project.py` 第 32 组 12 条：快照能还原素材/音频/节奏、空快照不炸、栈上限、1.2 秒合并窗口、快捷键、两页签、历史行可点回、重放期间不再记步骤、记历史动作 ≥14 处（实际 17）。全绿。
- 窗口冒烟 `PIC2VIDEO_SHOT_UNDO=1`（3 张图）：`clips=3 index=1/1 ['打开','加图片']` → 删除后 `clips=2 index=2/2` → 撤回 `clips=3 index=1/2` → 再撤回 `clips=0 index=0/2`（回到打开时的空项目）→ 还原 `clips=3`；两页签文案「素材 / 历史」，历史 3 行，撤回/还原按钮的可用状态随位置变。
