# 10: 默认简洁模式 + 深浅主题 + 主色对撞色 + 色环取色

Type: task

Status: resolved
## Question

用户 m01167 提的三件事里有两件互相纠缠、要一起落到 pic2video.py 的窗口层：默认第一次打开进简洁模式；菜单支持深色/浅色主题，并让用户只挑一个主色，工具自动算色环 180° 的对撞色，取色方式改成色环。

## 定稿（用户 m0117x 回答）

- 主题三档：跟随系统（默认）/ 浅色 / 深色。
- 主色 + 互补色：主色用在按钮、选中、时间线色带；对撞色只给进度条、播放头这类点缀；其余中性灰。
- 取色器换成色环（外圈色相 + 中间 S/V 方块），对话框里并排显示主色与自动对撞色。
- 首次打开默认简洁模式（`Settings.DEFAULTS["ui"] = "simple"`），工具条右侧「简洁模式 / 专业模式」可随时切、可记住。

## 落点

`.scratch/pic2video/theme.py`（新增，纯 Python：主题、色环对撞、对比度、22 键调色板、QSS 生成、Windows 系统主题读取）；
`pic2video.py` 的 Settings / SettingsDialog / Window.apply_theme / ColorWheelDialog / Timeline.set_colors / _theme_assets。

## Answer

已完成并验证。

**实现**
- 新增 `theme.py`（纯 Python，不 import Qt）：三档主题、`palette(theme, accent)` 出 22 个颜色键、`complementary()` 按色环 +180° 算对撞色、`readable_accent()` 保证按钮文字对比度、`build_qss()` 生成整套 QSS、`system_theme()` 读 Windows `AppsUseLightTheme`。
- `pic2video.py`：`Settings` 新增 `theme`（auto/light/dark）与 `accent`；`SettingsDialog` 加「界面主题」「主色」两行；新 `ColorWheel` / `ColorWheelDialog`（色环 + S/V 方块 + 主色/对撞色两块色卡）；`Window.apply_theme()` 贴 QSS 并喂时间线配色；`Timeline` 色带用主色，隔一块明度 ±12%，播放头用对撞色；`_theme_assets()` 按配色现画下拉/微调箭头 PNG（缓存在 `%TEMP%/pic2video_ui_<hash>`）。
- `Settings.DEFAULTS["ui"] = "simple"`：第一次打开就是简洁模式。

**验证**
- 单测 `probe/test_project.py` 全过（新增主题组：22 键调色板、深浅底色不同、正文对比度 ≥7、按钮文字压主色 ≥4.5、对撞色色环 175–185°、QSS 含主色与对撞色；并断言首次打开 ui=="simple"、theme=="auto"）。
- 窗口冒烟：深色+简洁+#e11d48、浅色+专业+#0ea5e9 两组均 exit 0；色环对话框 450×395 正常；截图 `probe/shots/shot_settings_zh-CN_simple_dark_acc.png`、`shot_settings_zh-CN_pro_light_acc.png`、`shot_wheel_zh-CN_simple_dark_acc.png`。
- 修掉两个 Windows QSS 坑：`border` 三角在 Windows 画不出来（改成生成 PNG 箭头）、微调按钮写 `height:50%` 无效（改 13px 固定）。
