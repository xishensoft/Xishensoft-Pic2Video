# 07: 画面比例档位与背景（颜色/图片/视频/模糊）可配

Type: task

Status: resolved
## Question

用户 m00649 要求「画面比例这一块也靠提问来」，于是用提问定下了比例与背景的细节（m00649 回答）：
比例要加 21:9 宽银幕、3:4 竖版海报、2:3 竖版；分辨率要「宽高两个都能填，比例只当预设」；
留白「可以自定指定颜色，或者是自己指定图片或视频作为背景，还可以选择给背景加上模糊或者不加模糊」。

## 决议

- 比例档位：16:9 / 9:16 / 1:1 / 4:5 / 4:3 / 21:9 / 3:4 / 2:3 / 自定义；选档位按「短边 1080」自动填宽高，手改宽高则比例自动跳「自定义」。
- 分辨率改为宽、高两个可手填整数（16–4096，自动取偶数），比例只是预设。
- 铺底五种：原图铺底（own）/ 纯色留白（color，颜色可自选）/ 自定义背景图（image）/ 自定义背景视频（video）/ 裁切铺满（cover）。
- 背景模糊变成独立开关 bg_blur：own 时决定底图模不模糊，image/video 时决定背景模不模糊。
- 老配置兼容：blur→own、black→color。
